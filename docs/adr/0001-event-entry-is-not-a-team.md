# An event entry is the public side; a team is the person set

Fans see an event entry, named for the skip and scoped to one event. A team is one discipline plus the set of people on the main roster, and it is a new team when one of those people changes. There is no season-long franchise keyed by the skip. The site uses that split so a lineup change is not hidden inside a stable "Team Homan," and so the same four players at a later event stay one team with two entries.
